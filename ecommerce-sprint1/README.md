# E-commerce — Sprint 1

Módulo de catálogo y detalle de producto correspondiente al Sprint 1 (HU-01 y HU-02).

## Funcionalidades

- Catálogo de productos: vista en grid responsivo (2 columnas en móvil, 3 en tablet/desktop) con tarjetas de producto (imagen, nombre, precio y disponibilidad).
- Detalle de producto: vista con galería de imágenes, nombre, precio, disponibilidad y descripción.
- Navegación entre catálogo y detalle.
- Tablero de seguimiento: panel visual con el estado final de las tareas del sprint.
